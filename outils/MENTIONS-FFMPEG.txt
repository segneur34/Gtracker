Gtracker, programme Windows : bibliothèque FFmpeg

Ce programme utilise des bibliothèques du projet FFmpeg sous LGPL 2.1.

La bibliothèque est celle de Chromium, embarquée par Electron : c'est le fichier
ffmpeg.dll du dossier du programme (à côté de Gtracker.exe).

Code source
  Dépôt FFmpeg de Chromium :
    https://chromium.googlesource.com/chromium/third_party/ffmpeg
  La révision utilisée est celle qu'indique le fichier DEPS de la version de
  Chromium qu'embarque la version d'Electron de ce programme (la version
  d'Electron est donnée par le fichier « version » à côté de Gtracker.exe).
  Projet FFmpeg :
    https://ffmpeg.org/download.html
